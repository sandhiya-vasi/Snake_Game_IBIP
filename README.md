# 🐍 Snake Game
A classic Snake Game built with **Python** and **Pygame**, featuring multiple difficulty modes, a menu screen, and restart functionality.

---

## 📖 Project Overview
The **Snake Game** is a fun arcade‑style project that demonstrates **game development basics** such as event handling, collision detection, and rendering graphics. It includes a menu, difficulty modes, restart option, and score tracking.

---

## ✨ Features
- 🎮 **Difficulty Modes**: Easy, Medium, Hard  
- 🖥️ **Menu Screen**: Start button and mode selection  
- 🐍 **Snake Controls**: Arrow keys + on‑screen buttons  
- 🍎 **Food System**: Randomly generated food with score tracking  
- 🔄 **Restart Option**: Play Again button after Game Over  
- 📊 **Score Display**: Real‑time score tracking  

---

## 🛠 Tools and Libraries
- **Python** → Core programming language  
- **Pygame** → Game development library for graphics and sound  
- **Git** → Version control for project management
