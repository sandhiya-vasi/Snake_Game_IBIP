# Snake Game 🎮

## 📖 Project Overview
This project is a classic **Snake Game** built using **Python** and the **Pygame library**.  
The player controls a snake that moves around the screen, eats food to grow longer, and must avoid collisions with walls or itself.  
Scores are displayed live during gameplay, and high scores are saved persistently in a text file.

---

- **Python** → Core programming language  
- **Pygame** → Game development library for graphics, events, and sound  
- **VS Code** → Development environment  
- **GitHub** → Version control and project hosting

6. **Scoring System** → Displayed live score and saved high scores in `scores.txt`.  
7. **Testing & Debugging** → Fixed path errors and ensured smooth execution in VS Code.
